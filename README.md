# Rebuild estático de estudiodecabida.cl

Incluye:
- Home optimizada para conversión y SEO
- Páginas consistentes de precio, casos, contacto y comuna
- Header/footer unificados
- Favicon implementado en todas las páginas
- robots.txt y sitemap.xml
- Formulario que abre WhatsApp con mensaje prellenado

## Deploy
Puedes subir esta estructura tal cual a GitHub Pages, Netlify, Vercel o cualquier hosting estático.

## Nota sobre favicon
Se dejó implementado exactamente este tag en todas las páginas:
<link rel="icon" href="/assets/favicon.png" type="image/png">

Además se agregó fallback SVG para que no se rompa mientras subes tu favicon PNG real a /assets/favicon.png.
